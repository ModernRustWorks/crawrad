A file change proposal generated by one of the agent's tools.

# Examples

```rust
use crawrad_agent::DiffReview;
use std::path::Path;

let review = DiffReview::new(1, Path::new("test.rs"), "a\n", "b\n", "edit");
assert_eq!(review.id, 1);
assert!(review.is_pending());
```
