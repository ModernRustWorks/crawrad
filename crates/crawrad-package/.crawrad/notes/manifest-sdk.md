The version of the contract that this IDE speaks.

It increases when the format stops accepting something it accepted — and **not**
when it starts accepting more. A new field with a default is an addition, and an
older manifest remains valid.

**The number lives in THE BOX**, and not here. Whoever WRITES the manifest is
`crawrad_component::manifest!`, on the machine of whoever publishes a component; whoever
REFUSES it is this function, on the machine of whoever installs. Two constants would be
two chances to disagree — and the disagreement would appear as a package
generated by this codebase being rejected by the IDE that came with it.

# Examples

```rust
use crawrad_package::manifest::SDK;

assert!(SDK >= 1);
```
