Where each slice of a card's right column is written, from top to
bottom.

It is the BOX path; that of the inner label is DERIVED from it in the painter, and not
written alongside — two lists with the same name written twice is the
silent divergence this shell has already paid for.

A list in Rust and not three loose calls: it is what ties the number of
DSL boxes to the model's `packages::FATIAS_DE_ESTATISTICA`, and a gate
checks both. Without this, a fourth statistic would disappear in silence.
