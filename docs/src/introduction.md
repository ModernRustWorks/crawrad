# Introduction

CrawRAD is a visual IDE for Rust. You draw a form, set properties in the
Object Inspector, write the event code, and CrawRAD generates and runs a real
Rust app — native, web or mobile — from the same form.

## How this manual is organised

The manual follows four kinds of page. Each kind answers a different question,
so you always know where to look:

| Part | Answers | Read it when |
|---|---|---|
| [Tutorials](tutorials/README.md) | "Teach me." | You are new and want to learn by building something. |
| [How-to guides](how-to/README.md) | "How do I…?" | You know what you want and need the steps. |
| [Reference](reference/README.md) | "What exactly is…?" | You need the precise detail of a component, property, menu or shortcut. |
| [Concepts](concepts/README.md) | "Why does it work this way?" | You want to understand the ideas behind the IDE. |

Greyed-out chapters in the menu are planned and not written yet.
